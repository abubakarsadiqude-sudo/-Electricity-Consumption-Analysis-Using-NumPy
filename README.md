# Electricity Consumption Analysis Using NumPy

## Project Description
This project analyzes the weekly electricity consumption of five houses using Python and NumPy. It performs data analysis, calculates electricity bills, compares consumption, and applies basic data normalization techniques.

## Features

### Part A: Basics
- Display array shape, size, dimensions, and data type.
- Extract weekly data for House 3.
- Extract Friday consumption for all houses.
- Separate weekend data using array slicing.

### Part B: Analysis
- Calculate weekly consumption for each house.
- Calculate daily average consumption.
- Identify the highest and lowest electricity-consuming houses.
- Find the day with the highest total consumption.
- Compare weekday and weekend average consumption.

### Part C: Filtering and Decisions
- Find all readings greater than 20 units.
- Count readings greater than 20 units.
- Identify houses with above-average weekly consumption.
- Calculate electricity bills using conditional rates.
- Categorize houses as High Usage or Normal Usage using `np.where()`.

### Part D: Challenges
- Rank houses by weekly electricity consumption.
- Normalize data between 0 and 1.
- Simulate a 20% increase in House 3 consumption.
- Preserve the original array while creating a new array.

## Electricity Billing Rules

| Weekly Consumption | Rate |
|---|---|
| 100 units or less | Rs. 25 per unit |
| More than 100 units | Rs. 35 per unit |
